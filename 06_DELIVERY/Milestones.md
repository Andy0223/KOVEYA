# Milestones

| 里程碑 | 驗收條件 | 狀態 |
|---|---|---|
| M0 Foundation | 規格追蹤、可執行本機專案、migration、CI、公開頁 | 本機與 GitHub CI 通過（v0.1） |
| M1 Identity & Provider | 安全登入、同帳號雙模式、品牌與服務發布 | v0.6 Founder 雲端 Email／Google 已實測；品牌圖片與完整上線驗收待補 |
| M2 Booking Loop | 直接／申請預約、取消、改期、歷史與防撞 | v0.3–0.6 本機回歸及部分 Founder 雲端證據；Founder 自測回報可用，完整獨立驗收待完成 |
| M3 Operations | CRM、通知、ICS、管理與稽核 | CRM／站內通知／ICS 已實作；交易 Email、管理、Cron 獨立驗證待補 |
| M4 Closed Beta | 所有 P0、手機、安全、併發、備份復原及獨立審查 | 未開始 |
| M5 Public Beta | 3–5 真實供給方、50 真實測試預約、客服與監控 | 未開始 |

完整年度門檻見 [Roadmap](../01_PRODUCT/Roadmap.md) 與 [KPI](../00_STRATEGY/KPI_Framework.md)。所有數字為目標，不代表達成。
