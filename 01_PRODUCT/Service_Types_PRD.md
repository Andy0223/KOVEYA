# Service Types

| 模式 | 初期流程 | 階段 |
|---|---|---|
| Instant | 選服務／時段 → 驗證 → 原子成立 | MVP |
| Request | 提出 → 供給方審核或提議 → 重查資源 → 成立 | MVP |
| Package | 定價／次數／期限 → 分配 → 完成扣次 → 續購 | P1 |
| Event | 場次／容量 → 報名 → 名額確認 → 報到／完成 | P2，版本名稱 V1.5 |
| Quote | 需求／附件 → 報價版本 → 雙方確認 → 訂單 | P2 |
| Project | 已接受提案 → 里程碑 → 交付 → 驗收 → 結案 | P3 |

共用服務目錄、身分、客戶、訂單、通知與權限，不強迫所有模式共用一個狀態欄位。

套票異動使用不可任意覆寫帳本，事件唯一性防重扣。團課名額以資料庫容量保護，不超賣。報價接受記錄版本與接受者，不能單方修改已接受價格與範圍。

待報價服務的 MVP 審核及價格同意規則尚待完成，不能用零元代表待報價。
