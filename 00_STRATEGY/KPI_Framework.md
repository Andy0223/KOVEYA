# KPI Framework

北極星：Monthly Completed Services，每月成功完成的服務數。以有權限者完成的有效服務事件計數，需排除測試與重複事件，取消與未出席不算完成。

| 面向 | 指標 |
|---|---|
| 獲取 | 新供給方、首次發布比例、來源轉換 |
| 啟用 | 供給方註冊後 7 天首筆有效預約、需求方首約成功率 |
| 核心使用 | 完成服務數、自助預約率、改期時間 |
| 留存 | 供給方 30／90 天、需求方再次預約 |
| 商業 | MRR、ARPA、付費轉換、每筆預約成本 |
| 品質 | 撞期、交易錯誤、通知失敗 |
| 網路 | 跨供給方使用率、自然邀請 |

漏斗：服務頁 → 預約點擊 → 服務選擇 → 時段 → 確認 → 成立 → 完成 → 再次預約／續購。

初期目標：至少 70% 有效預約自助完成、修正後測試供給方 30 天留存至少 60%、正式開放前修復所有已知重大一致性問題。比例同時報告分母、樣本數、服務類型與觀察期間；這些是目標，沒有實際量測結果。


## 新增：客戶關心與操作助手（規劃指標）

| 能力 | 應觀察 | 解讀界線 |
|---|---|---|
| 客戶關心 | 符合資格人數、名單採用／略過、聯絡整理時間、客戶暫停／退訂／負面回饋 | 未預約不直接視為失去動機；排除測試與不適合聯絡者 |
| 關心後回約 | 以去重客戶計算 7／14／30 天內有效再次預約與完成服務，明列觀察窗及分母 | 先區分教練自行回報、渠道確認發送、點擊及完成；小樣本相關性不是提醒造成的增量 |
| 文字助手 | 草稿正確率、重要欄位修正率、釐清／放棄、從輸入到完成的時間與成功率 | 與同任務原表單比較；草稿生成不算建立服務／預約成功 |
| 語音 | 人名／日期／時間／數字／否定詞錯誤、校正次數、裝置相容性、延遲、單次成本 | 依語言／噪音／裝置分組，沒有錄音或辨識權限時的表單回退也需量測 |
| 操作安全 | 未確認寫入、越權、重複交易、錯誤對象／時區或自動冒稱成功 | 不允許已知此類重大缺陷隨新入口上線；原核心交易品質門檻繼續適用 |

先建立基準再與 Founder 訂定提升目標，不先承諾回約率增幅。北極星仍是每月完成服務數；提醒數或 AI 呼叫數不是價值指標。詳見 [產品補充](../01_PRODUCT/Client_Care_and_Action_Assistant_PRD.md)。
