# Exception Flows

| 情境 | 使用者體驗 | 系統要求 |
|---|---|---|
| 時段剛被搶走 | 說明時段已不可用，回選時段 | 不留部分交易 |
| 登入驗證逾時 | 可重寄，保留合法服務意圖 | 不重用一次性 token |
| 申請逾時 | 清楚顯示已過期 | 接受操作與到期競爭須有條件寫入 |
| 改期新時間撞期 | 告知失敗，原預約仍在 | 舊占用及歷史不能遺失 |
| Email 失敗 | 預約頁狀態仍正確 | 背景記錄及重試 |
| 服務下架／供給方停權 | 無新預約入口 | 保留已成立歷史及依責任處理原安排 |
| 私人資料越權 | 拒絕並提供一般錯誤 | 不洩漏另一租戶是否有該物件 |
| 重複提交 | 回同一結果 | actor + operation + key 冪等 |
| 系統未初始化 | 可理解的載入失敗與重試 | 503，不洩漏資料庫細節 |

錯誤提示不能宣稱通知已讀、銀行已驗證付款或退款已成功，除非具備對應證據。
