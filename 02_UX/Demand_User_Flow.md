# Demand User Flow

D-01：Instagram／LINE／WhatsApp／TikTok 連結 → 服務頁 → 服務 → 價格、時間、政策 → 時段 → 必要聯絡資訊 → 驗證身分 → 確認 → 已成立或待審核 → 我的預約。

D-02：直接預約最後提交時，重新檢查服務、時段、政策與必要資源；成功提供編號與 ICS。MVP 顯示現場或依既有方式付款，不虛構支付確認。

D-03：申請有到期時間；供給方接受、提議新時段或拒絕。提議需要需求方回覆，正式成立前重新檢查資源。

D-04：取消先顯示政策與可能費用，再確認；改期選新時間並提交，失敗保留原預約。涉及未實作套票／金流時，不顯示自動退次或退款成功。

D-05：完成後查看歷史、再約，未來加入權益及續購。下一步依既有服務關係，而非無差別推薦。
