# Supply User Flow

S-01：約五分鐘完成第一個可分享預約連結。Email 驗證 → 我要提供服務 → 個人／品牌 → 模式 → 名稱、價格、時長 → 交付方式 → 可用時間 → 確認與取消政策 → 預覽 → 發布 → 分享。

不強制先完成 CRM、金流或外部行事曆整合。草稿自動保存需有狀態說明，發布時後端完整驗證。

S-02：登入 → 今日待辦 → 新預約／待審核 → 安排 → 履約 → 完成／未出席 → 服務紀錄 → 後續服務。

S-03：供給方提出改期，需求方接受或拒絕；未接受前原預約保留。如原時段確實無法履約，採供給方取消／特殊異動，不能默認對方已同意。

S-04：首約 → 客戶關係 → 完成 → 歷史 → 後續套票／固定安排 → 合規提醒 → 續購。
