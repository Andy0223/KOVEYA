# Design System v0.1

目前為工程可用的視覺起點，尚未經使用者研究及完整 WCAG 驗收。

方向：溫暖、清晰、專業，讓個人服務者與需求方都能快速理解。背景 `#faf9f5`、主要文字 `#203b32`、主要動作 `#254e40`、點綴土色 `#a16840`；表面與分隔以低飽和綠及灰為主。

系統字體優先，避免外部字體請求。主標題清楚分級；主要按鈕至少 44px 高、鍵盤焦點可見、提供跳至主內容。顏色之外使用文字表達狀態。

桌面內容寬度 1180px，主要手機斷點 700px，最窄驗證 320px。導覽可換行；表單未來需有 label、欄位錯誤與總結。尊重 prefers-reduced-motion。

狀態包含 Loading、Empty、Error、Success；開發預覽及虛構資料明示，避免顯示假的帳號或營運成果。

目前樣式見 `src/web/styles.css`；元件庫將隨實際表單及交易流程提取，避免先建過大的設計框架。
