# Security Tests

| 區域 | 必測案例 |
|---|---|
| Email | token 過期、重放、同時消耗、枚舉、寄送與驗證限流 |
| Session | 失效、撤銷、停權、cookie 設定、登出後重試 |
| 授權 | 改 ID／org_id／client_id 越權、需求方查他人、業者查其他租戶 |
| 交易 | 竄改價格／幣別／政策、非法狀態、重放與冪等衝突 |
| Web | 同源與 CSRF、open redirect、輸入 XSS、回應錯誤洩漏 |
| 檔案 | 大小、格式、惡意檔名、來源與可見權限 |
| 營運 | 管理員存取理由、最小權限、稽核、Secrets 與 log 洩漏 |

目前私人 API、登入及管理介面尚未實作。資料庫跨租戶 FK 已有測試，但不等於 API IDOR 驗收。正式上線前由獨立於實作者的審查角色完成，報告版本、案例、結果及未修復問題。
