# Go / No-Go

## 封閉 Beta

- [ ] 所有 P0 功能及對應案例驗收。
- [ ] 無未修復已知重大安全漏洞。
- [ ] 無已知有效預約撞期或重複扣次缺陷（套票啟用時）。
- [ ] 完成備份及復原演練，記錄 RPO／RTO。
- [ ] 真實手機完成主要操作。
- [ ] Email／D1／網域／環境隔離與監控就緒。
- [ ] 條款、隱私、取消政策、資料匯出刪除及客服流程就緒。
- [ ] 交易與安全由獨立角色簽核。

## 公開 Beta 額外條件

- [ ] 至少 3–5 位真實供給方測試。
- [ ] 至少 50 筆真實測試預約。
- [ ] 明確回報渠道及客服責任。
- [ ] 重要錯誤可監控與追蹤。
- [ ] 能處理帳號、預約與資料異常。

目前尚未達任何 Beta 上線門檻；Foundation 的通過結果僅對應已實作範圍。
