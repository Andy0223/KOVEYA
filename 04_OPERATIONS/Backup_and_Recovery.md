# Backup & Recovery

狀態：僅具備本機 migration 重建，尚未執行正式資料備份還原演練。空庫重建不等於業務資料復原。

正式使用前依 D1 當時支援的備份／Time Travel 能力、方案限制及保留期間制定作業。RPO、RTO、頻率與責任人尚待設定；不能當成已承諾 SLA。

演練步驟：建立含預約、占用、歷史及 Outbox 的測試資料 → 記錄備份點與雜湊／筆數 → 模擬損毀 → 還原至隔離資料庫 → 檢查外鍵、快照、時段占用及事件 → 跑核心流程 → 記錄資料損失範圍與實際耗時 → 獨立審查。

還原後外部通知與金流事件可能已發送，須以事件 ID／供應商 reference 對帳，不能盲目重送。事故修復保留稽核紀錄。
